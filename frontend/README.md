# Craftora Frontend

This Next.js application is the frontend foundation for the Craftora emergency wearable platform.

## Phase 1 goals

- initialize the App Router
- configure TypeScript and Tailwind CSS
- create a clean API service layer
- create types, hooks, and reusable UI foundations
- keep all business logic in the Laravel backend

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local development

```bash
npm run dev
```

The app is intentionally kept minimal in this phase and does not include business features yet.
